Structure of folder data_src_decon_20250528:

We have saved single Michel candidates with wvfs of the full run. 
The next is to select wvfs further for each Michel candidates.

wvf_coincidence_MULTI_merged.py:
It will save the group of maximum timing coincidence (PDS) for each candidate

print_wvfCoin_merged.txt will record the print of wvf_coincidence_MULTI_merged.py execution


wvf_coincidence_MULTI_applyCut.py:
It will work on the dataset generated by wvf_coincidence_MULTI_merged.py
Apply certain cut on # (wvf coincidence), it keeps survivors in a new folder

print_wvfCoin_applyCut.txt will record the print


wvf_coincidence_MULTI_count.py:
It will read dataset generated by wvf_coincidence_MULTI_merged.py
Then count the number of waveforms each candiate;
Storing the count at ./print_wvfCoin_count.txt


michel_peakFinder_MULTI.C:
It will process the dataset generated by wvf_coincidence_MULTI_applyCut.py
Peak Finder: To find the peak location of Michel candiates;
Location of muon peak is stored at peakFinder_muonTime.txt;
Location of Michel peak is stored at peakFinder_michelTime.txt;
Number of peakFinder coincidence is stored at peakFinder_michelCoincidence.txt
